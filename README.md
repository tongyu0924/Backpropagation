# Backpropagation

This project implements a basic two-layer neural network using only NumPy.

The network is trained on randomly generated data to demonstrate forward propagation, backward propagation, and parameter updates using gradient descent. This is useful for learning how neural networks work under the hood without relying on deep learning libraries like TensorFlow or PyTorch.

### Features
- Manual implementation of forward and backward propagation
- Binary cross-entropy loss
- Sigmoid activations
- One hidden layer with 8 units
- Optimized using vanilla gradient descent
